# PRD 020 Collection Filtering WebMCP Tool

Update `useCollectionFilterTool` to create a tool which can be used by agents to update the
currently displayed collection to filter and sort it.

The agents should also be able to filter the collection and get information about the games
included in that filtered set in order to answer basic questions about a user's collection.

For example, "how many games do I own which can be played with 2 players?"

Filters should not update the current collection view unless the agent requests it.
